### 2.1 主线关卡进度系统
| 文件 | 功能 |

### 2.2 战斗结算流程
| 文件 | 功能 |
|------|------|
| `UI/HomePageRouter.cs` | 结算弹窗（战斗胜利）：5 个按钮 + 防连点锁 |

**状态**：✅ 完成。按钮锁防止重复发奖，结算文案区分首次/重复通关。

### 2.3 主线详情弹窗按钮状态优化
| 功能 | 说明 |
|------|------|
| 未解锁关卡 | 显示"未解锁"提示，隐藏阅读/战斗按钮 |
| 可挑战关卡 | 正常显示"开始阅读"+"进入战斗" |
| 已通关关卡 | 显示"回看剧情"+"重复挑战"+"再次战斗"，文案明确不重复推进 |

**状态**：✅ 完成。三态按钮逻辑由 `LevelProgressManager` 驱动。

### 2.4 编队页与战斗页联动
| 文件 | 功能 |
|------|------|
| `Network/ShouyouBackendBootstrap.cs` | `HasBattleReadyFormation`：编队为空禁止战斗<br>`GetFormationSummary`：动态读取编队摘要<br>`GetFormationPower`：战力占位算法 |
| `UI/HomePageRouter.cs` | `EnterBattlePrototype` 两级守卫（解锁→编队）<br>`GetFormationSlotLabel`：槽位动态标签 |

**编队规则**：6 人编队（前排 3 + 后排 3），至少 1 人才可战斗。后端未启动时 Demo 默认队伍兜底。  
**状态**：✅ 完成。

- 中文注释（面向中文团队的协作文档化注释）
- null 安全（所有公开方法都有 Instance null 检查和兜底）
- 边界防御（`Mathf.Clamp`、数组长度保护）
- Demo 临时方案标注（PlayerPrefs、硬编码战力值，均已注释说明后续替换方向）
