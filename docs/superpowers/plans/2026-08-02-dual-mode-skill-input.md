# 双模式技能输入（Todo25）

## 目标

让行动值队列仍然唯一决定谁真正行动，但技能按钮能直观区分两种结果：

- 当前行动角色：点击大招后立即结算，消耗行动点并结束本次行动。
- 已选中、但不是当前行动者的我方角色：点击大招只预选，保留到该角色下一次行动；不会抢占当前行动，也不会提前扣除行动点或进入冷却。

## 范围

- 只改 `BattleDemoController.cs` 和技能预选静态校验。
- 加入按钮文案和颜色状态：立即、预选、已预选、行动点不足、CD。
- 已预选同一技能再次点击时取消预选。

## 非目标

- 不改伤害、治疗、行动值、冷却、后端、数据库、结算结构。
- 不增加动画队列；后续任务才会把攻击者高亮、施法、受击、飘字拆成时间序列。

## 验证

1. 静态校验检查当前行动即时分支、非当前预选分支和预选取消分支。
2. 既有战斗循环、目标反馈和编队到战斗校验仍通过。
3. Unity Play Mode：当前行动角色释放大招立即结算；选择另一名存活队友后预选不结束当前行动；该队友下一次行动自动释放；CD/行动点不足状态可读。
