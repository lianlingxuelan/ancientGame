# 第一章剧情播放 UI 接入计划

## 目标

将已审查通过的 `MainlineStoryPlaybackState` 接入现有主线关卡详情弹窗，让“开始阅读 / 重读剧情 / 回看剧情”真正使用同一份逐句播放和已读记录状态。

## 范围

- 修改 `HomePageRouter.cs` 的剧情详情入口、逐句推进、跳过、关闭与切换关卡逻辑。
- 新增一个只检查 UI 接入关系的静态验证脚本。
- 不修改场景、后端、数据库、资源、支付、关卡开放规则或战斗公式。

## 验收

1. 页面不再拥有第二套剧情行号、计时器或直接已读写入路径。
2. 读剧情时逐句显示、三秒后可跳过、末句完成均委托给 `MainlineStoryPlaybackState`。
3. 关闭详情或切换关卡只重置临时播放状态，不回滚已读记录。
4. 静态检查和既有剧情目录/播放状态/关卡引导检查通过。
5. Unity Play Mode 手动验证第一关：开始阅读、逐句推进、三秒后跳过、完成后回看按钮可用。
