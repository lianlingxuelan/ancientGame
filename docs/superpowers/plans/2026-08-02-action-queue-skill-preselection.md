# 行动队列与技能预选（Todo22）

## 已确认的产品规则

- 行动者由 `actionValue` 决定；头像点击只查看状态或选择敌方目标，不能改变当前行动者。
- 底部三个大招可在当前我方行动时预选；预选本身不扣行动点、不进入冷却、不造成伤害。
- 预选技能在该角色的下一次行动开始时自动释放；执行时才结算行动点与冷却。
- 普攻继续作为即时行动，避免本轮同时改变普攻交互与技能预选交互。
- 本轮不改伤害公式、后端、数据库、资源或战斗结算结构。

## 实现步骤

1. 在 `BattleDemoController` 建立按战斗单位保存的预选技能状态；重置/阵亡时清理。
2. 将三个大招入口改为“预选并结束本次行动”，保存单体目标槽位以便下次行动时优先命中；目标已退场时回退存活目标。
3. 在玩家行动结束后的行动队列推进中，自动处理到达行动回合的预选技能；执行路径沿用原有伤害、治疗、飘字和头像表现请求。
4. 让技能按钮显示“预选中”且禁止当前行动者重复预选；保持普攻和自动战斗的既有功能。
5. 以静态契约脚本检查关键入口与清理路径，交 Claude 做 Unity Play Mode 回归审查。

## 验收边界

- 不新增 Controller，不调用后端，不触碰 `ShouyouServer/data/shouyou.db`。
- 技能预选不改变 `CalculateDamage`、`CalculateSkillDamage`、`CalculateAreaSkillDamage`、`CalculateHealAmount` 的公式。
- 仅作为第一版战斗交互骨架；正式版的行动条、技能目标指示和动画表现另行接入。
