# 主线剧情完成引导计划

## 目标

让玩家读完或跳过一段主线剧情后，立刻理解下一步应该做什么，同时明确剧情已读不等于战斗通关或奖励已领取。

## 范围

- 仅修改 `HomePageRouter` 的剧情完成文案。
- 使用既有关卡目录、奖励目录和进度管理器读取状态。
- 不改变战斗数值、奖励发放、解锁规则、后端、数据库、场景和资源。

## 规则

1. 本关未通关：提示进入战斗，并展示“战斗胜利后可获得”的奖励预览。
2. 本关已通关且不是最终关：提示回看、重战和前往已开放的下一关。
3. 最终关已通关：提示本章主线完成，可回看或重复挑战。
4. 所有提示只读取状态，不写存档和资源。

## 验证

- 新增静态验证脚本，检查引导分支依赖真实进度与奖励目录。
- 回归剧情播放状态、剧情目录与关卡引导验证脚本。
- Cloud 在 Unity Play Mode 验证未通关、已通关和最终关三种文案与按钮语义。
