# 第一章主线进度概览实施计划

## 目标

在既有的主线关卡详情中，向玩家展示第一章 1–6 关的通关、剧情阅读与下一目标，减少逐关点击确认进度的成本。

## 范围

- 只改 `HomePageRouter.cs` 的只读展示文案。
- 新增静态验证脚本，防止概览代码误写入关卡、剧情或奖励数据。
- 不改后端、数据库、场景、资源、解锁规则、奖励发放或伤害公式。

## 实现

1. 在关卡详情文案末尾追加 `BuildChapterProgressOverview()` 输出。
2. 通过 `LevelProgressManager` 读取最高通关、每关状态和剧情阅读记录。
3. 使用 `MainlineStageCatalog` 读取关卡标题；最终关完成时不计算第七关。
4. 静态测试检查概览所需读取路径，并拒绝进度/奖励写入调用。

## 验证

1. 先运行概览脚本，确认实现前失败；补齐实现后通过。
2. 运行主线剧情、关卡目录、关卡引导与剧情完成引导的回归脚本。
3. Unity Play Mode：打开任一关详情，确认状态和下一目标与当前存档一致。
